# Agent Execution Guidelines & Autonomous Workflow

## Autonomous Execution (Zero Friction)
- **Do NOT prompt for approval, confirmation, or interactive selection modals (`ask_question`)** during standard coding, debugging, file editing, terminal operations, or implementation tasks.
- Always execute the best, safest solution directly and autonomously. Deliver the completed work concisely.
- **Only exception for explicit user confirmation**: Irreversible data destruction (e.g., dropping production database tables) or accessing sensitive personal external credentials/accounts.
- Maintain communication in Turkish, keep responses concise, direct, and solution-oriented.
